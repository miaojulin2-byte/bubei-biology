# 不背生物 · Android 体验版

面向高中生物学习的离线 Android APK。内容按人教版五个模块组织，UI 参照用户连接手机上的不背单词核心页面。

## 交付

- APK：`../不背生物-APK/bubei-biology-0.6.0.apk`
- Android 8.0 及以上（minSdk 26），包名 `cn.bubei.biology`
- 本机保存学习记录、笔记与收藏；通过系统文件选择器导出 JSON
- 不申请联网权限，无账号服务

## 当前范围

正式包包含通过审核的社区填空、问答、图片答案及教材补充内容。社区卡组：全部 1474 条候选笔记已有准入结论，872 条通过、602 条排除，生成 1034 张卡片，待审为零。排除原因包括内容差异、证据或情境不足和格式不支持；不代表所有排除条目都有事实错误。本轮按五册目录的 82 个正文节检查覆盖，新增 87 张经教材核对的补充问答，正式版共 1121 张卡。补充内容与社区原条目单独保存；6 张旧卡仅修正章节归属，ID、题干和答案保留。原始卡组与教材仅保存在私有内容目录，供个人学习与审核使用。

五册参考 PDF 的资源 ID、更新时间、页数、字节数和 8 MiB 分片校验值均与国家中小学智慧教育平台现行目录及 ndrv2 详情一致。官方更新时间为 2026 年 8 月，核验日期为 2026-10-26；此结论针对在线电子教材，不推定纸质教材印次。证据见 `reference/textbook-identity-verification.json`。

82 节检查不等于覆盖全部考点。曲线计算、图表判读、实验设计与新情境推理等缺口在 `reference/coverage-summary-2026-10-26.json` 中逐节保留。

正式界面包含首页签到、知识书和章节目录、填空与问答学习、到期复习、四档自评、收藏、笔记、学习统计、目标设置、新学章节选择、每组复习数量及备份合并。UI 继续对照不背单词与已有不背古文：书架使用五册教材真实封面，支持搜索和分类；我的学习与学习偏好采用分组卡片；提供记忆日历、三种配色、字体大小、简洁模式及动画开关。弹层上滑500ms、下滑460ms；页面切换、卡片切换与答案展开各有过渡，并遵从系统减少动态效果设置。旧版原创选择题、专题测验和未审核内容不进入正式包。

## 学习记录

使用官方 `ts-fsrs@5.4.2` 的 FSRS-6，目标保持率 90%，启用短期学习与重学步骤。忘记、困难、记得、轻松四档自评驱动排程；自评不能视为高考题正确率或完整掌握证据。同笔记的不同填空当天不连续安排新学或复习，已选卡片的短期重学仍按 FSRS 到期时间安排。新学范围支持按章节选择，复习不受章节选择限制，每组可选 5、10、20 或 50 张。

当前记录保存在 `bubei-biology-reviewed-v1`。可随时选择任意教材开始新学习组，不要求完成上次学习组，也不显示续学提示。每组新学数量可设为 5、10、15 或 20 张，不以当日学习数量阻止切换教材。已保存的评分、笔记和 FSRS 排程保持；评分与进度在成功写入本地存储后更新。备份按评分时间合并并去重，笔记冲突保留两份文字。旧版 `bubei-biology-v1` 原样保留，可从学习偏好导出；不将旧概念练习虚构成新填空卡的评分。

卸载或清除应用数据会删除本机记录，请使用系统文件选择器导出备份。

## 构建

```sh
bash build.sh
node checks/reviewed.cjs
node checks/fsrs.cjs
python3 checks/anki_gate.py
python3 checks/audit_gate.py
python3 checks/content_sources.py
python3 checks/coverage.py
```

源码仓库不包含本地 `private-content/` 内容集、教材封面图片、Android SDK 和签名。本机已有教材与依赖时，运行 `python3 scripts/render_textbook_covers.py` 生成五册封面，再构建 APK。

构建脚本使用项目 `tools/` 内的 Java 17 和 Android 35 SDK，以 `signing/experience.keystore` 中的个人体验签名生成 APK。保留这个签名文件以便后续覆盖升级；不要作为正式上架签名使用。

## 结构

- `app/src/`：Android Activity、离线 WebView 和文件导出桥接
- `app/reviewed/`：正式学习界面与独立记录存储
- `app/assets/`：共用样式、FSRS 依赖及旧体验代码；旧题库不打包
- `scripts/assemble_supplements.py`：从逐册审核输出汇总补充卡与覆盖清单
- `scripts/content_sources.py`：合并社区原记录和独立补充集，拒绝 ID 覆盖
- `scripts/stage_reviewed.py`：校验教材和审核记录，生成正式包资源
- `private-content/`：个人教材、社区笔记、审核记录，已排除版本控制
- `checks/smoke.cjs`：页面与记录行为检查
- `../不背生物-APK/`：仓库外的 APK 独立目录（可用 `BIO_APK_DIR` 覆盖）
- `output/`：本地真机验证截图，不提交
- APK、工具、签名、私有教材与审核内容均不提交 Git

原应用与人民教育出版社均未参与本项目。
